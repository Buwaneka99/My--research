## 4. ඔයාගේ part එකට එයාගෙන් ගන්න පුළුවන් දේවල් (priority order)

ඔයාගේ known defects ලිස්ට් එකට හරියටම match වෙන ඒවා මුලින්:

**1. [eval_statistics.py](Graphsage/scripts/eval_statistics.py) — කෙලින්ම copy කරන්න.** Multi-seed mean±std + bootstrap 95% CI + **paired bootstrap** delta vs baseline. ඔයාගේ ලොකුම ablation ප්‍රශ්නය (Config A vs B/C/D controlled නෑ, difference එකක් significant ද කියලා කියන්න බෑ) මේකෙන් විසඳෙනවා. Score blob loader එක විතරක් වෙනස් කරන්න ඕන. Config E/F/G කරද්දී මේක එක්කම කරන්න.

**2. Threshold protocol එක — [threshold_tuning.py](Graphsage/src/graphsage/training/threshold_tuning.py) + "tune on val, freeze, report test".** ඔයාගේ Config D එකේ tuning split එකම evaluate කරන ප්‍රශ්නයට හරියටම මේක තමයි fix එක. Notebook එකේ justification එකත් citation එකත් තියෙනවා (scikit-learn `TunedThresholdClassifierCV`, Elkan 2001) — report එකට කෙලින්ම දාන්න පුළුවන්.

**3. [calibration_study.py](Graphsage/scripts/calibration_study.py) + ECDF percentile calibration.** ඔයාට මේක දෙපැත්තකින් වටිනවා: (i) reliability diagram + ECE — DSAA signals valid ද කියලා පෙන්නන්න; (ii) **ECDF percentile trick එක** ([predictor.py:62-79](Graphsage/src/graphsage/inference/predictor.py#L62-L79)) — TRANSFER සහ CASH_OUT strata දෙකේ scores scale දෙකක තියෙන ප්‍රශ්නය, monotone transform එකකින් comparable කරන්න පුළුවන් (ranking, AUROC වෙනස් වෙන්නේ නෑ).

**4. [temporal.py](Graphsage/src/graphsage/data/temporal.py) — leakage-free snapshot protocol.** ඔයාගේ VAE pipeline එකත් full timeline එක උඩ features/scaler හදනවා නම් ඒකෙත් එම ප්‍රශ්නයම තියෙනවා. අඩුම තරමේ framing එකයි justification එකයි ගන්න.

**5. Dashboard + visualization — [dashboard/app.py](Graphsage/dashboard/app.py) (47KB).** ඔයාගේ visualization deliverable එකට හොඳම starting point. Streamlit + Plotly + glassmorphic CSS + `@st.cache_resource` patterns + interactive network graph. [static/demo.html](Graphsage/src/graphsage/api/static/demo.html) එකත් බලන්න.

**6. Cloud වැඩේට — [train_colab.ipynb](Graphsage/notebooks/train_colab.ipynb).** Colab + Drive pattern එක ready: repo branch clone → Drive mount → artifacts copy → train → **timestamped `colab_runs/<stamp>/` එකට archive**. ඔයාගේ notebooks 05+ ඒ විදිහටම cloud එකට ගන්න පුළුවන්.

**7. FastAPI endpoint එකට architecture එක.** ඔයාට `/api/v1/behavioral/classify` හදන්න ඕන — [app.py](Graphsage/src/graphsage/api/app.py) එකේ `create_app(predictor=None)` factory pattern එක, startup එකේදී heavy state load කරලා request එකට lookup විතරක් කරන එක, checkpoint mtime එකෙන් key කරපු score cache එක, `RequestValidationError` → contract error handler එක — ඔක්කොම කෙලින්ම ගන්න පුළුවන්. [test_api.py](Graphsage/tests/test_api.py) එකේ `FakePredictor` pattern එකෙන් **big artifacts නැතුව** tests ලියන්න පුළුවන් — ඒක ඔයාට ගොඩක් වටිනවා.
